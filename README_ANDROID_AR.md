# قافلة الصحراء — Desert Convoy (Android)

هذا مشروع Android Studio لتشغيل لعبة HTML5 محليًا داخل Android WebView. تم تطوير النسخة الموجودة وإضافة:
- مراحل مهمة متتابعة: جمع 3 إمدادات، تعطيل 3 حراس، ثم الوصول إلى نقطة العبور.
- زر إطلاق يعمل باللمس أو بمفتاح المسافة.
- حراس يطلقون النار، ومؤثرات إصابة ومقذوفات.
- موارد الوقود وقطع الغيار وحالة المركبة.
- رسومات جانبية مع طبقات خلفية تعطي إحساسًا بالعمق.

## إنشاء APK
هذا الأرشيف مشروع Android Studio وليس APK جاهزًا. لم يمكن بناء APK مباشرة في بيئة الإنشاء الحالية لعدم توفر Android SDK وGradle.
1. فك ضغط الأرشيف.
2. افتح مجلد `Desert_Convoy_Android` في Android Studio.
3. ثبّت Android SDK Platform 35 إن طُلب منك، وانتظر Gradle Sync.
4. اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ملف APK التجريبي سيظهر عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

التطبيق يفتح أفقيًا وبملء الشاشة، ومحتوى اللعبة محفوظ في مجلد assets ولا يحتاج إلى خادم.
