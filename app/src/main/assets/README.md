# قافلة الصحراء — Desert Convoy

لعبة قيادة ومغامرات ثنائية الأبعاد تعمل في المتصفح باستخدام HTML5 Canvas وJavaScript، مع دعم أولي لشاشات اللمس.

## التشغيل
- افتح `index.html` في متصفح حديث.
- لا توجد عملية بناء أو تثبيت مطلوبة.
- للنشر، ارفع الملفات الثلاثة إلى أي استضافة صفحات ثابتة تدعم HTML.

## التحكم
- `W` أو `↑`: تسارع.
- `S` أو `↓`: فرامل.
- `A` أو `←`: إمالة للخلف.
- `D` أو `→`: إمالة للأمام.
- زر `Ⅱ`: إيقاف مؤقت.
- على الهاتف: استخدم أزرار اللمس أسفل الشاشة.

## النسخة الحالية
- عالم صحراوي متحرك مع طبقات خلفية وتضاريس مولدة.
- مركبة مرسومة برمجيًا، تسارع وإمالة وقفز بسيط.
- الوقود وحالة المركبة.
- صناديق تعيق الطريق، وقود إضافي، وقطع غيار.
- هدف مسافة أولي وشاشة فوز/إعادة المحاولة.

## خطة التطوير المقترحة
1. ضبط الفيزياء والتصادمات بناءً على اختبار اللعب.
2. إضافة مراحل وبيئات مختلفة ونظام حفظ التقدم.
3. إضافة مرآب لترقية المحرك والتعليق والوقود.
4. إضافة مهام وأحداث طريق وأعداء وعناصر تفاعلية.
5. إضافة أصوات وموسيقى وخيارات وصول.
6. تحسين الأداء وتثبيت واجهة الهاتف ثم نشر اللعبة.

## ملاحظات
هذه نسخة أولية قابلة للعب وليست الإصدار النهائي. بعض العناصر الفنية مرسومة على Canvas مؤقتًا بدل ملفات رسومات خارجية، مما يجعل التجربة سهلة النقل والتعديل.
